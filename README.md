# FitApp

PWA local para registro de alimentação, calorias, macronutrientes, metas, peso e acompanhamento por dashboard.

## Atualizações desta versão

- Banco de alimentos ampliado com alimentos cotidianos e preparações brasileiras.
- Informações nutricionais dos alimentos limitadas a kcal, proteína, carboidratos e gordura por 100 g.
- Alimentos adicionais referenciados em bases brasileiras TACO/TBCA.
- Cadastro, edição e exclusão de alimentos personalizados pelo próprio usuário.
- Nova paleta visual predominantemente verde.
- Dark mode com fundo realmente escuro.
- Nova aba Dashboard com períodos de 7, 14, 30 e 90 dias.
- Dashboard com médias, aderência à meta, calorias por dia, evolução de ingestão, macros e alimentos de maior contribuição calórica.

Os dados continuam locais, sem servidor.
